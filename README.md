# GPU Page

A static landing page for a GPU virtual machine product (titled "GPU Instances - Next Gen Computing with H100"), presented as a web design. It is two files with no build step and no dependencies.

## Contents

- `index.html`: the page, with inline JavaScript.
- `style.css`: styling.

Sections on the page: hero, "What You Get" (feature cards), "Powering Your Innovation" (technology overview), "Why Choose Our H100 GPU Instances?", "Technical Specifications", and a closing call to action ("Start Your GPU Journey Today").

Interactions in the inline script: a loading screen that hides after the page loads, animated background particles, smooth-scrolling anchor links, and card hover effects.

## Running

Open `index.html` in a browser, or serve the folder with any static server, for example:

```bash
python3 -m http.server 8000
```
